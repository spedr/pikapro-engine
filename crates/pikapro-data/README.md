# pikapro-data

The game data of [pikapro-engine](https://github.com/spedr/pikapro-engine), a
Pokémon battle simulator faithful to Pokémon Showdown: species, moves,
abilities, items, natures and the type chart, generated from
[Pokémon Showdown](https://github.com/smogon/pokemon-showdown)'s data at
the commit pikapro is checked against. Two dexes share one ID space:
`gen9` (Scarlet/Violet) and `champions` (Showdown's Pokémon Champions
mod). The `legality` feature adds learnsets, events and the rest of what
team validation needs.

The crate holds data only, no behaviour; the simulator is the
[`pikapro`](https://crates.io/crates/pikapro) crate. It is `no_std` (with
`alloc`) and has no dependencies. Every entry has a compact ID and a
constant naming it.

```rust
use pikapro_data::gen9::{moves, species};
use pikapro_data::{Type, champions, gen9};

let garchomp = gen9::DEX.species(species::GARCHOMP);
assert_eq!(garchomp.base_stats.0, [108, 130, 95, 80, 85, 102]);
assert!(garchomp.types.contains(Type::Dragon));

// Champions changes some moves: Protect has 5 PP there.
assert_eq!(gen9::DEX.move_(moves::PROTECT).pp, 10);
assert_eq!(champions::DEX.move_(moves::PROTECT).pp, 5);

assert_eq!(gen9::DEX.species_by_name("flutter mane"), Some(species::FLUTTER_MANE));
```

The tables are generated by `tools/datagen` in the
[repository](https://github.com/spedr/pikapro-engine); see the
[main README](https://github.com/spedr/pikapro-engine/blob/main/README.md).
